# E-Commerce Product Review Sentiment Analysis

**Domain:** Data Science & Machine Learning

## About This Project
Customers leave thousands of reviews on e-commerce sites every day. Reading them one by one to know if a customer is happy or not is very time-consuming. In this project, we build a simple Machine Learning model that automatically reads a review and tells us whether it is **Positive**, **Neutral**, or **Negative**.

This is a great beginner project because it touches almost every core skill in a Data Science role:
- Reading and cleaning real-world data
- Basic Exploratory Data Analysis (EDA) with charts
- Working with text data (Natural Language Processing basics)
- Training a Machine Learning classification model
- Evaluating how good the model is

## What We Will Do (Step by Step)
1. Load the dataset
2. Clean the data (remove missing values, duplicates, etc.)
3. Explore the data with simple charts
4. Clean the review text (remove punctuation, stopwords, etc.)
5. Convert text into numbers using TF-IDF
6. Train a Logistic Regression model
7. Check how accurate the model is
8. Test the model on new, custom reviews
